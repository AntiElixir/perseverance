# 需求文档

## 1. 应用概述

### 1.1 应用名称
标签化智能专注计时Web应用

### 1.2 应用描述
面向大学生、研究生的专注计时工具，通过标签化任务分类、智能分心监测和数据可视化分析，帮助用户提升专注效率并清晰掌握时间分配情况。采用本地数据存储保护用户隐私，提供免费基础功能和高级分析订阅服务。

### 1.3 项目背景
目标用户自律性较弱，现有工具无法按任务分类记录时间，手动拆分数据繁琐。本应用通过AI智能配置、自动化标签归档和轻量分心干预，解决用户痛点。

### 1.4 商业模式
免费基础功能 + 高级分析订阅。UI需预留高级订阅功能的专属标识或锁形图标。

### 1.5 技术背景说明
开发框架：React/Next.js  
样式方案：Tailwind CSS  
图表库：Recharts或类似工具  
数据存储：localStorage本地存储

## 2. 用户与使用场景

### 2.1 目标用户
- 大学生、研究生
- 需要长时间专注学习或工作的人群
- 希望量化时间投入并优化专注效率的用户

### 2.2 核心使用场景
- 考研/考公/职业资格备考
- 期末复习/课程作业
- 论文写作/课题研究
- 日常阅读/自我提升
- 工作办公

## 3. 页面结构与功能说明

### 3.1 页面结构

```
├── AI智能初始配置引导页（首次访问弹窗）
├── 主计时页面
│   ├── 倒计时/正向计时器
│   ├── 任务标签选择/新建
│   ├── 开始/停止按钮
│   └── 分心提醒弹窗
├── 目标管理页面
│   ├── 目标设置模块
│   └── 进度展示模块
└── 数据仪表盘页面
    ├── 时间分布图表
    ├── 标签维度统计
    └── 分心记录模块
```

### 3.2 AI智能初始配置引导页

#### 3.2.1 触发条件
新用户首次进入网页时自动弹出引导弹窗。

#### 3.2.2 引导问题
弹窗包含3个单选问题，设计目标为10秒内完成：

**问题1：主要使用场景？**
- 考研/考公/职业资格备考
- 期末/课程作业
- 日常阅读/自我提升
- 工作办公

**问题2：单次持续专注时长？**
- <25分钟
- 25-45分钟
- 45-60分钟
- >60分钟

**问题3：是否需要自动休息提醒？**
- 需要
- 不需要

#### 3.2.3 匹配规则
基于用户选项自动匹配预设专注方案模板：
- 考研/考公 + 45-60分钟：专注50分钟 + 休息10分钟，默认标签「公共课复习/专业课复习/刷题/复盘」
- 期末/课程作业 + 25-45分钟：专注30分钟 + 休息5分钟，默认标签「课程A/课程B/作业/复习」
- 日常阅读 + <25分钟：专注20分钟 + 休息5分钟，默认标签「专业书籍/闲书/文章」
- 工作办公 + >60分钟：专注90分钟 + 休息15分钟，默认标签「项目A/项目B/会议/邮件」

#### 3.2.4 方案展示与应用
展示「为你匹配的专属专注方案」卡片，包含：
- 专注时长与休息时长
- 默认任务标签列表
- 「一键应用」按钮：点击后直接进入主计时页面
- 「手动调整」按钮：允许用户修改时长和标签后再应用

### 3.3 主计时页面

#### 3.3.1 计时器显示
- 显眼的大号数字时钟，展示倒计时或正向计时
- 当前任务标签名称显示在时钟下方

#### 3.3.2 任务标签选择/新建
- 开始计时前，强制或引导用户选择已有标签或新建标签
- 标签示例：专业课、论文、阅读、课题等
- 新建标签：用户输入标签名称后保存

#### 3.3.3 开始/停止按钮
- 开始：启动计时器，记录开始时间
- 停止：结束计时器，记录结束时间，自动归档数据并关联到当前标签

#### 3.3.4 分心监测与干预
利用浏览器Page Visibility API或焦点事件监测用户行为，所有数据仅在本地处理。

**轻度分心触发条件：**
- 用户切出网页超过30秒
- 或在页面超1分钟无操作

**轻度分心触发动作：**
- 网页标签页title闪烁
- 播放轻柔提示音
- 页面展示轻量文案（如：「别走神哦，还差一点就完成本次专注啦」）

**中度分心触发条件：**
- 用户切出网页超过2分钟
- 或连续切出网页3次以上

**中度分心触发动作：**
- 页面弹出强制提醒弹窗
- 弹窗内展示用户今天的总体专注目标进度（如：「你今天的目标是专注4小时，当前已完成1.5小时，继续加油」）
- 用户必须手动点击「回到专注」按钮才能关闭弹窗

#### 3.3.5 专注结束反馈
结束专注时，弹出或实时更新进度条，展示：
- 本次专注时长
- 今日已完成总时长
- 距离目标还差多少

### 3.4 目标管理页面

#### 3.4.1 目标设置模块
支持按日/周/月设定目标：
- 按标签设定目标（如：本月论文写够30小时、课题做够25小时）
- 按总时长设定目标（如：本周总专注时长达到40小时）

#### 3.4.2 进度展示模块
- 进度条展示已完成时长与目标时长的对比
- 达到目标时，触发正向激励提示（动画或烟花效果）
- 未达标时，给出温和的调整建议（如：「距离目标还差5小时，建议每天增加1小时专注时间」）

### 3.5 数据仪表盘页面

#### 3.5.1 时间分布图表
- 按标签维度拆分总专注时间
- 通过饼图或柱状图展示不同任务的时间投入占比（如课题 vs 论文 vs 闲书）

#### 3.5.2 标签维度统计
- 展示每个标签的累计专注时长
- 支持按日/周/月筛选数据

#### 3.5.3 分心记录模块
- 展示用户的分心次数
- 标注高频分心时段（如：每天14:00-16:00分心次数最多）
- 帮助用户定位注意力薄弱点

#### 3.5.4 高级订阅功能标识
在数据仪表盘页面的高级分析功能区域，预留锁形图标或专属标识，提示用户订阅后可解锁更多分析能力。

## 4. 业务规则与逻辑

### 4.1 数据归档规则
- 每次结束专注时，自动记录：开始时间、结束时间、专注时长、关联标签、分心次数
- 数据存储在本地localStorage，确保用户隐私

### 4.2 分心监测规则
- 轻度分心：切出网页超过30秒或页面超1分钟无操作
- 中度分心：切出网页超过2分钟或连续切出3次以上
- 分心次数累计记录，用于数据报表分析

### 4.3 目标达成判定规则
- 按标签或总时长判定目标是否达成
- 达成时触发正向激励提示
- 未达成时给出调整建议

### 4.4 AI匹配规则
根据用户在引导页的选择，自动匹配预设专注方案和默认标签模板。

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 用户未选择标签直接开始计时 | 强制弹窗提示用户选择或新建标签，不允许跳过 |
| 用户中途关闭浏览器或刷新页面 | 数据自动保存到localStorage，重新打开时恢复计时状态或提示用户是否继续上次专注 |
| 用户设定的目标时长为0或负数 | 提示用户输入有效的目标时长（大于0） |
| 用户删除标签后，该标签下已有历史数据 | 提示用户确认删除，删除后历史数据标记为「已删除标签」，不影响统计 |
| 用户在分心提醒弹窗中不点击按钮 | 弹窗持续显示，阻止用户继续操作，直到点击「回到专注」按钮 |
| 用户浏览器不支持Page Visibility API | 降级为仅监测焦点事件，或提示用户升级浏览器 |
| 用户设定的专注时长超过24小时 | 提示用户输入合理的专注时长（建议不超过4小时） |

## 6. UI/UX设计原则

### 6.1 极简沉浸
计时主界面剔除一切多余干扰元素，突出大号数字时钟和当前任务标签。

### 6.2 色彩心理
采用令人内心平静的色调（如莫兰迪色系、深空灰或护眼绿），避免高饱和度刺眼色彩。

### 6.3 响应式设计
确保在不同尺寸的显示器以及分屏模式下，页面都有良好的排版表现。

### 6.4 高级订阅标识
UI需预留高级订阅功能的专属标识或锁形图标，提示用户订阅后可解锁更多功能。

## 7. 验收标准

1. 新用户首次访问时，自动弹出AI智能初始配置引导弹窗，完成3个问题选择后，展示匹配的专注方案并点击「一键应用」进入主计时页面
2. 在主计时页面选择或新建任务标签，点击「开始」按钮启动计时器
3. 计时过程中切出网页超过30秒，触发轻度分心提醒（title闪烁+提示音+文案）
4. 点击「停止」按钮结束专注，数据自动归档到对应标签，并弹出进度反馈展示本次时长和目标完成情况
5. 进入数据仪表盘页面，查看按标签维度拆分的时间分布图表和分心记录模块
